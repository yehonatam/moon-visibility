# ראיית הירח

חישוב אסטרונומי של ראיית הירח החדש לקביעת ראש חודש.

- **index.html** – טבלה שנתית: לכל חודש בשנה העברית, זמן המולד ונתוני הראייה בערב הראשון ובערב השני, כולל הערכת ראייה לפי Yallop ו-Odeh.
- **moment.html** – רגע נתון: כל נתוני השמש והירח לדקה ולמקום שבוחרים, עם שרטוט של האופק המערבי.
- **astro.js** – החישובים האסטרונומיים (לפי Meeus, *Astronomical Algorithms*), ושני העמודים משתמשים בהם.

האתר סטטי לגמרי, בלי שרת ובלי שלב בנייה. הוא מבוסס על התוכנה "חזון שמיים" ונבדק מול נתוני DE440 של NASA ומול תצפיות ICOP.
